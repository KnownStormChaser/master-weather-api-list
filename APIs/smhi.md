### SMHI (Open Data)

Sweden's national meteorological and hydrological institute, publishing a genuinely developer-friendly point-forecast API alongside observations, analysis, and fire-risk services. The forecast product — SNOW, a meteorologist-curated 2.5 km grid covering roughly the Nordics and the Baltic region — answers a plain lat/lon request with ten days of JSON and needs no key, no signup, and no attribution beyond CC BY.

- **Based in:** Norrköping, Östergötland, Sweden (Sveriges meteorologiska och hydrologiska institut, a government agency under the Ministry of Climate and Enterprise)
- **Access model:** No key required — public HTTPS REST endpoints under `opendata-download-*.smhi.se`, queried directly with no signup. GET only. Note that SMHI's developer portal also documents some services restricted to authorized clients whose use "is bound to a charge," with keys issued by SMHI Customer Service; those sit alongside, but are not part of, the open data set
- **Pricing model:** Free (open public-service data; no paid tiers on the open APIs — SMHI's commercial products are sold separately)
- **Coverage / data types:** **Meteorological forecast (SNOW1gv1)** — point forecast by lat/lon returning ~24 parameters per time step: air temperature, wind speed/direction/gust, relative humidity, mean-sea-level pressure, visibility, cloud cover total plus low/medium/high, cloud base and top altitude, thunderstorm probability, probability of precipitation, probability of frozen precipitation, predominant precipitation type, a weather symbol code (1–27), and an unusually rich precipitation set carrying deterministic, mean, median, min and max amounts. Query parameters trim the response by parameter list (`parameters=`) and time-step count (`timeseries=`). A multipoint request returns one parameter across the whole Swedish grid for a single valid time, with an optional `downsample` factor of 1–20. **Fire weather index forecast (FWIF)** — fire-risk forecast by point or multipoint, daily out to 6 days (representing the afternoon peak) and hourly for the next 48 hours. **Meteorological observations (metobs)** — Swedish station observations as an INSPIRE download service, traversed parameter → station → period. **Meteorological analysis (Mesan2gv2)** — gridded analysis, the companion product to SNOW. **Hydrological observations (hydroobs)** — river and water-body station data
- **Free tier:** the entire open data set is free with no key and no published per-user quota. SNOW forecasts run at least 240 and up to 251 hours ahead so that ten full days are always covered; observation history depth varies by parameter and station
- **Paid tiers:** none on the open APIs
- **Rate limits:** none published (fair use). Multipoint requests require the client to accept gzip encoding or the API returns HTTP 406
- **Output formats:** JSON for the forecast and analysis services; metobs additionally offers XML, Atom, and CSV, with the version/parameter/station/period levels each available in all four
- **Geographic strength:** Sweden. The SNOW forecast domain is a 2.5 km grid bounded roughly by the corners 50.32 N/0.28 E, 72.76 N/-18.12 E, 71.58 N/54.24 E and 49.77 N/33.03 E — approximately the Nordic and Baltic region — and a point request returns the nearest grid point within it. Whole-grid multipoint requests, observations, and hydrological data are Sweden-only
- **Notable limitations:** **the previous forecast API, PMP3gv2, was retired on 31 March 2026** and now returns 404 — SNOW1gv1 is not a drop-in replacement, since the response moved from a nested `parameters[]` array to a flat `data` object, `validTime` became `time`, short codes became human-readable names (`t` → `air_temperature`, `Wsymb2` → `symbol_code`), coordinates flattened, and the `approvedtime.json` endpoint was removed entirely, so most third-party libraries and tutorials predating April 2026 are broken or stale. Temporal resolution thins out across the forecast: hourly for roughly the first two and a half days, then six-hourly, then twelve-hourly at the far end. The multipoint (full-grid) query covers Sweden rather than the whole SNOW domain, and SMHI warns that downsampled grids can misrepresent lakes and mountain tops and should be used for visualisation only, not analysis. The observations API is shaped as an INSPIRE download service — one parameter, one station, one time window per request — so assembling a full picture for a station takes many calls, and there is no coordinate lookup. No archived or historical forecasts are served, and no severe-weather-warning product appears among the documented open data APIs. The documentation portal is a JavaScript-rendered single-page site that blocks automated access, so the parameter reference and symbol table can only be read in a browser, and some metadata remains Swedish-only. Data is licensed CC BY 4.0, so attribution to SMHI is required
- **Built on:** SNOW (Swedish National Operational Weather forecast) is a forecast database quality-controlled by a duty meteorologist, who selects input from a number of forecast models and applies post-processing; it is the same product behind smhi.se and the SMHI app, and its min/max/median precipitation fields indicate ensemble input. SMHI does not publicly enumerate which underlying NWP models feed it
