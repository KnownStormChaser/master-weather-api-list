### Bright Sky

Free, key-less JSON API that repackages the German weather service's open data — DWD station observations, MOSMIX point forecasts, the 1 km rain radar, and official CAP warnings — behind a clean REST interface. Not a DWD product: it's an independent open-source project run by one developer, funded by donations and a past government grant.

- **Based in:** Germany — operated personally by Jakob de Maeyer as an open-source side project; there is no company, imprint, or postal address on the site, and the country is inferred from the Prototype Fund / Federal Ministry of Education and Research grant that funded development (the programme requires German residency)
- **Access model:** No key required — public HTTPS REST endpoints at `api.brightsky.dev`, no signup, no registration, no User-Agent requirement. CORS is open to all origins. The full stack is published, so you can also self-host your own instance
- **Pricing model:** Free (donation-funded public service; no paid tiers exist and the maintainer states the goal is to run it without charging users or introducing quotas)
- **Coverage / data types:** five endpoints — **`/current_weather`** (best-effort current conditions compiled from the last 90 minutes of SYNOP reports), **`/weather`** (hourly observations *and* MOSMIX forecasts through one endpoint, selected by date range), **`/synop`** (raw ten-minutely SYNOP observations, last 30 hours), **`/radar`** (1 km × 5-minute precipitation radar, past six hours plus a two-hour nowcast), and **`/alerts`** (official DWD warnings in German *and* English, resolved to municipality warn cells). A `/sources` endpoint handles station lookup. Parameters include temperature, dew point, relative humidity, sea-level pressure, cloud cover, visibility, wind speed/direction/gusts, precipitation, precipitation probability (forecasts only, 1 h and 6 h), sunshine duration, solar irradiation, and a derived condition/icon field. Units switchable between DWD-conventional and SI; timestamps returned in any tz-database timezone
- **Free tier:** the entire API is free for all purposes, including commercial use; historical records go back to 1 January 2010 (deeper history requires self-hosting). No per-key quota exists because there are no keys
- **Paid tiers:** none — no commercial tier, no priority access, no support contract
- **Rate limits:** none published and none apparently enforced; the public instance serves upwards of two million requests per day. Heavy users are pointed at the infrastructure repo to run their own instance rather than at a paid plan
- **Output formats:** JSON. Radar precipitation is returned either as a nested integer array (`plain`) or as a base64 string, optionally zlib-compressed (`compressed`, the default and by far the fastest)
- **Geographic strength:** Germany. Observations, radar, and alerts are Germany-only; MOSMIX forecasts do extend worldwide, but at far lower station density outside Germany
- **Notable limitations:** station-based, not gridded — a lat/lon query resolves to the nearest source within `max_dist` (50 km default, 500 km ceiling), so coverage quality depends on station spacing, and outside Germany that spacing gets thin fast; radar, alerts, and observations are Germany-only; historical data starts in 2010, SYNOP records are kept only 30 hours and radar only six; the radar grid is a polar stereographic projection that must be reprojected before overlaying on standard web maps, and the full 1200×1100 frame set is large enough that bounding boxes are strongly recommended; alerts cover only DWD's ~11,000 municipality cells, not the ~400 district cells; no marine, tide, air-quality, pollen, climate-normal, or map-tile products. Operationally this is a single-maintainer service on a single VPS with no SLA, no uptime guarantee, and no support commitment beyond email and GitHub issues. The server code is MIT-licensed, but the **data** is governed by the DWD's terms of use, so DWD attribution obligations apply to anything you retrieve
- **Built on:** DWD open data exclusively, parsed from `opendata.dwd.de` — MOSMIX (`local_forecasts/mos/`) for forecasts, CDC climate observations for history, POI reports for the current day, synoptic JSON reports for current conditions, the RADOLAN RV composite for radar, and CAP `COMMUNEUNION_DWD_STAT` for alerts. No blending, modelling, or bias correction of its own; the parsing core is published separately as `dwdparse`
