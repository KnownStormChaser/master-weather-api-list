### LVĢMC (Latvian Environment, Geology and Meteorology Centre)

Latvia's national meteorological and hydrological service, publishing forecasts, observations, and warnings as open datasets on the national open-data portal rather than through a purpose-built weather API. There is no developer portal and no API key — instead, CKAN's DataStore exposes every table to SQL queries over HTTP, so a forecast for one town or one coordinate is a single URL. Everything is released into the public domain under CC0.

- **Based in:** Riga, Latvia (Latvijas Vides, ģeoloģijas un meteoroloģijas centrs, a state-owned company acting as the national hydrometeorological service). The API layer itself is Latvia's open data portal, `data.gov.lv`, operated by the State Digital Development Agency
- **Access model:** No key required — public HTTPS endpoints on the national open-data portal, no signup. Data is reachable two ways: bulk CSV download per resource, or the CKAN DataStore API (`/api/3/action/datastore_search` and `datastore_search_sql`), which accepts arbitrary read-only SQL against each table and returns JSON. LVĢMC pushes each new forecast to the portal as soon as it is produced
- **Pricing model:** Free (open public-service data; no paid tiers)
- **Coverage / data types:** four datasets. **Populated-place forecasts** — hourly for the next 24 hours and daily for the next 7 days across roughly 6,500 Latvian populated places, filtered by `CITY_ID`, with a place list, a 20-entry parameter list, and a weather-pictogram lookup table. **Spatial forecasts** — 9-day gridded forecasts queryable by coordinate, bounding box, or nearest grid point, covering air temperature, apparent temperature, relative humidity, mean-sea-level pressure, hourly precipitation, precipitation phase, precipitation probability, wind speed, direction and maximum gust, total cloud cover, fog intensity index, thunderstorm probability, snow depth, probability of sub-zero 2 m temperature, and UV index. **Hydrometeorological observations** — meteorological and hydrological station measurements for the past 48 hours, a 365-day archive (both actuals and daily avg/min/max), observed weather phenomena, plus station and parameter metadata. **Hydrometeorological warnings** — warning metadata with phenomenon, onset and end time, impact assessment and advice, joined to affected municipalities and to warning polygons
- **Free tier:** everything is free with no key and no published quota. Forecast horizons are 24 hours hourly and 7 days daily for places, 9 days for the grid; the observation archive runs 365 days
- **Paid tiers:** none
- **Rate limits:** not published. Practical limits are those of the portal's CKAN DataStore rather than anything LVĢMC states
- **Output formats:** JSON from the DataStore API; CSV for whole-resource downloads
- **Geographic strength:** Latvia only — populated places, grid, stations, and warning areas are all within the country
- **Notable limitations:** this is a national open-data catalogue, not a weather API — there is no developer portal, no versioned endpoints, no status page, and the query layer, uptime, and any rate limiting belong to the portal operator rather than to the met service, so the two are coupled in a way a first-party API wouldn't be. Data comes back in long format: one row per location, parameter ID, and timestamp, with the value in a `VERTIBA` column, so assembling a usable forecast object means joining against the parameter and pictogram lookup tables and pivoting client-side — there is no single call that returns a readable forecast. Field names, parameter descriptions, and all dataset documentation are Latvian-only. Timebases differ between products: the populated-place forecasts are published in Latvian local time while the spatial forecasts are in UTC, which is an easy source of silent off-by-hours bugs. Update frequency is listed as irregular, with the spatial forecast guaranteed only four times a day, and the precipitation-probability layer refreshed on its own separate schedule. Resolution varies within the spatial dataset — the precipitation-probability, sub-zero-probability, and UV layers use a coarser grid than the rest. The observation archive is capped at 365 days, and there are no radar, satellite, air-quality, or marine products. Warnings are issued per administrative municipality or polygon rather than per coordinate, and Riga is warned separately from the region containing it, so a naive lookup can return two overlapping warnings for the capital. All four datasets are CC0 1.0, so no attribution is legally required (crediting LVĢMC remains good practice)
- **Built on:** LVĢMC states that its forecasters combine output from several international numerical weather prediction centres and apply both algorithmic and manual post-processing before verifying and publishing; the specific source models are not named. Observations come from LVĢMC's own meteorological and hydrological station network, and warnings are written by its duty synoptic meteorologists and hydrologists
